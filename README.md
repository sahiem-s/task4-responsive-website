# task4-responsive-website
Make a Website Mobile-Friendly Using CSS Media Queries | Converted an existing desktop-only webpage into a fully mobile-responsive layout using CSS media queries. Identified fixed-width elements and large images, then optimized them for smaller screens by applying media queries (max-width: 768px). Adjusted layout by stacking columns vertically, reducing font sizes, fixing overflow issues, and ensuring all images scale properly inside their containers. Improved navigation by making the menu collapse/stack on mobile. Tested responsiveness using Chrome DevTools device toolbar. Final deliverable: updated CSS file with clean, functional responsive design.
